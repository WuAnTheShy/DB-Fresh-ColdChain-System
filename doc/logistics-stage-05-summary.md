# B 组物流完善阶段 5 总结

日期：2026-09-02

## 完成内容

- 建立供应商级物流状态机和非法跳转保护。
- 在供应商履约详情页增加轨迹时间线及事件登记表单。
- 轨迹事件支持状态、地点、描述、发生时间和运输温度。
- 温度越界自动转为冷链异常，超过预计送达时间自动转为延误异常。
- 事件写入继续复用 B 组事务并经 `ILogisticsService` 调用跨组 Provider。

## 兜底说明

当前 A 组没有轨迹事件写入接口，因此 `FallbackGroupALogisticsExtensionProvider` 使用进程内数据模拟，
并在所有返回中标记 `DataSource=FALLBACK`。承运商、时效、描述和温区阈值均来自配置，
没有散落在 Controller 或业务 Service 中。应用重启后模拟轨迹会消失，这一行为不能用于生产。

## 验证场景

- 合法的“已发货→运输中”事件成功提交。
- “已发货→已退回”等非法跳转被拒绝并回滚。
- 冷藏温度越界生成温控异常。
- 超过预计时间生成延误异常。
