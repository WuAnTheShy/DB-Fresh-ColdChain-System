# B 组物流完善阶段 4 总结

日期：2026-09-02

## 完成内容

- 将跨组运费返回值由单一金额扩展为结构化报价结果。
- B 组下单和结算批次统一使用结构化报价中的金额。
- 在 B 组订单表保存报价 JSON 快照，记录目的地、规则摘要、计费商品和计算时间。
- 创建订单响应返回同一份报价对象，避免金额和展示依据分离。
- 增加基础 DDL、增量迁移和静态 DDL 门禁。

## 跨组边界

B 组没有实现地区匹配、温区、首重、续重和包装费算法。结构化结果由
`GroupALogisticsServiceAdapter` 调用 A 组公开报价接口后形成；A 组算法改进可在不修改
B 组订单服务的情况下生效。

## 验证重点

- 单订单和结算批次均保存非空报价快照。
- 快照可反序列化并与订单运费金额、目的地一致。
- DDL 和增量迁移只修改 B 组 `Biz_Orders`。

## 下一阶段

在供应商工作台增加轨迹事件维护，展示温控和延误异常，并通过配置化兜底 Provider 模拟 A 组尚未提供的轨迹接口。
