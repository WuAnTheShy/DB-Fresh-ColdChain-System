# B 组物流完善阶段 3 总结

日期：2026-09-02

## 完成内容

- 新增供应商履约列表、详情和发货入口。
- 查询范围由供应商会话限定，不接受客户端指定其他供应商。
- 供应商可填写承运商、运单号、温区、预计送达时间和备注。
- B 组编排服务在订单事务内调用 A 组供应商级发货契约。
- 多供应商订单支持分别发货，全部发出后才推进订单状态。
- 重复发货通过 A 组状态查询和现有幂等能力直接返回既有结果。

## 数据边界

- 新增 Repository 查询只访问 B 组 `Biz_Orders`、`Biz_OrderDetails` 和 `Crm_Customers`。
- FEFO、库存扣减、发货单和批次溯源继续由 A 组负责。
- A 组高级物流能力缺失时，展示数据由配置化兜底 Provider 提供。

## 验证场景

- 供应商列表只返回本人订单。
- 供应商不能查看其他供应商明细。
- 多供应商全部发货后才更新订单状态。
- 重复发货保持幂等。

## 下一阶段

完善运费结果契约，按供应商子订单保存可审计的报价快照，并保证前端试算与最终下单使用同一服务端规则结果。
