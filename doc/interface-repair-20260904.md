## 本阶段修复范围

1. `FallbackGroupALogisticsExtensionProvider`：基础 `SHIPPED` 不再覆盖扩展物流状态；基础发货单查询后缓存快照，支持稳定事件编号和继续追加轨迹。
2. `OrderService`、`OrdersApiController`：消费者确认收货检查所属包裹已签收；自动收货和管理端完成检查全部包裹已签收。订单状态与响应中的操作标记共同约束入口。
3. `IOrderService`、`OrderService`：全额及部分退款支持可选外部事务。B 组不提交、回滚或释放调用方事务；异常传播给调用方。旧调用方式仍兼容，但不因此获得跨组原子性。
4. 场景测试：验证运输状态刷新、基础发货单恢复、未签收拒绝、自动及管理端完成条件、外部退款事务提交/回滚及写入失败时的事务归属。
